# ✦ Studix — Daily Planner

**Plan your day/ Stay focused/ Make progress.**

Studix is a simple and elegant daily planner designed to help you organize your tasks, manage your time, and track your daily progress.

## 🚀 Features

* **Daily Task Management** — Add and delete tasks easily.
* **Task Scheduling** — Assign a specific time to each task.
* **Progress Tracking** — Monitor your daily progress with a progress bar.
* **Task Filters** — View all, pending, or completed tasks.
* **Date Selection** — Plan and manage tasks for different days.
* **Automatic Saving** — Your tasks are saved in your browser using Local Storage.
* **Responsive Design** — Enjoy a clean interface across different screen sizes.
* **Simple and Clean UI** — A modern design with a beautiful purple theme.

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## 💻 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding tasks and organizing your day!
   !Don't Copy!

No installation or additional dependencies are required.

## 💾 Data Storage

Studix uses your browser's Local Storage to save tasks.

Your tasks remain available when you reopen the website in the same browser, provided the browser data has not been cleared.

**Note:** Tasks are stored locally and are not automatically synchronized across different devices or browsers.

## 🎯 Project Goal

The goal of Studix is to make daily planning easier, encourage consistency, and help users focus on what matters most.
